# SSW Schedule Merger

特定技能（Specified Skilled Worker）試験スケジュールの **CMSコンテンツ更新を半自動化** する単一HTMLツールです。
更新スケジュール（一号 / 二号）を、CMSからエクスポートした現行コンテンツ（JSON）へ名前ベースで反映し、貼り戻し用の **B′（minified JSON）** を生成します。

すべてブラウザ内で完結し、外部送信は一切ありません。`index.html` を開くだけで動作します（GitHub Pages 可）。

---

## 用語

| 記号 | 意味 |
|------|------|
| **A（一号データ）** | (i) セクション用の更新スケジュール。`■分野名` 区切りのテキスト |
| **A2（二号データ）** | (ii) セクション用の更新スケジュール。形式は A と同じ |
| **B** | CMSからエクスポートした現行コンテンツ。`(i)` `(ii)` 両セクションを含むJSON配列 |
| **B′** | A / A2 を B へ反映した結果。CMSへインポートし直すための minified JSON |

---

## 使い方

1. 上流ツールが書き出した **一号データ（.txt）** を上部左のゾーンにドラッグ&ドロップ
2. **二号データ（.txt）** を上部右のゾーンにドラッグ&ドロップ
   （クリックでファイル選択も可。**片方だけでも動作**します）
3. 下の欄に **B** をコピペ
4. **「変換を実行」** を押す
5. 照合表で対応関係を確認し、問題なければ **B′ をコピー** して CMS にインポート

---

## 変換ロジック（仕様）

### マッチング
- (i)(ii) とも **分野名で突き合わせる**（位置ではなく名前ベース）。
- **表記ゆれ（大文字小文字・前後空白・改行）は吸収**して一致判定。表示は元の文字列のまま。
- B のスロットに対応する分野が A 側に無い場合 → **そのスロットは変更せず**、赤行＋警告で表示。
  （多言語データで分野名がズレた場合に気づける。上流ツール側の名称を直して再実行する想定）
- A 側にあるのに B に反映先スロットが無い分野 → 「対応なし」として表示。データを持つ場合は ⚠ 表示。

### group の切替（表示 / 非表示）
- 分野のテーブルに **データ行がある** → 内容を差し替え、`group: "frame"`（表示）
- データ行が **無い**（テーブル自体が無い、または `<tbody>` が空） → `group: "ignore"`（非表示）

### テーブルの扱い
- **まるごと置換**。B に元々あった行は、A に無ければ削除される。
  （A は常にその分野の完全な最新リストである前提）

### セクション境界
- B 内の見出し `... (i) exam schedule` / `... (ii) exam schedule`（lv2）で (i)/(ii) を判定。
- 各セクション内で、`frame` 見出し直後の最初の `richtext` ブロックをスロットとして扱う。

### 出力
- B 全体を **minified JSON**（空白なし）として出力。キー順は元の B を保持。

---

## 照合表の見方

| 列 | 内容 |
|----|------|
| 分野名 A / 分野名 B | マッチした分野名（表記ゆれがあれば B 側に注記） |
| 照合 | ✓一致 / ✗Aに無し（変更せず）/ Bに無し |
| A テーブル | データ行数、または「空」 |
| 反映後 group | `frame` / `ignore` / 変更せず |

- 赤い行：B にあるが A に対応分野が無い（**未変更**・要確認）
- オレンジの行：A にあるが B に反映先が無い

---

## 注意点

- **コピーボタン**：`file://` で直接開くと `navigator.clipboard` が使えない環境があり、その場合は旧方式に自動フォールバック。GitHub Pages（https）では問題なし。
- **テーブル構造の不備**：セルが閉じていない等の壊れたHTMLは ⚠ 表示するが、そのまま通す。元データの修正は手動。
- B に貼り付けるデータには実クライアントの試験スケジュール本文が含まれるが、処理はローカル完結。リポジトリ公開可否（public/private）は運用ポリシーに従って判断。

---

## 確定仕様サマリ

- 対象：(i)=一号データ / (ii)=二号データ、B は両方を含む同一JSON
- マッチング：名前ベース、表記ゆれ吸収、不一致スロットは無変更＋警告
- group：データ行あり→frame / なし→ignore（空テーブルも ignore）
- テーブル：まるごと置換
- 入力：A/A2 はドラッグ&ドロップ（片方のみ可）、B は貼り付け
- 出力：minified JSON をコピーして CMS へ貼り戻し
